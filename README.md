# Tribute Page

## Objective
To design and develop a Tribute Page using HTML, CSS, and JavaScript that highlights the life, achievements, and contributions of an inspiring personality.

## Tools Used
- HTML
- CSS
- JavaScript

## Features
- Attractive and responsive design
- Biography and achievements section
- Images and descriptive content
- Interactive elements using JavaScript
- User-friendly layout

## Outcome
The Tribute Page was successfully developed and presents information about the chosen personality in a visually appealing and interactive manner.
